Loop Engineering System
Live · in continuous use

Built an autonomous coding loop that ships its own guarded pull requests — infrastructure for building infrastructure.

Goal in, reviewed PR out. One engineer's effective surface area stops being bounded by how fast they can type — it's bounded by how well the guardrails are designed. I used this system to build Sentinel's entire backend and frontend end to end, unattended, over multiple days.

  • Two independent models cross-review every change — one drafts, a second adversarially reviews — before a deterministic test gate, not either model's own judgment, decides merge or block.
  • Hard guardrails: a workspace jail, protected paths the loop can never write to (its own tests, its own gates), secret scanning, and a per-task cost cap.
  • Runs unattended on a scheduled service, self-directed against a written goal spec — planning, coding, review, and merge with no human in the per-task loop.
